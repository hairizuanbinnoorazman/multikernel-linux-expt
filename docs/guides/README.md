# Guides

- [`runtime-operator-quickstart.md`](runtime-operator-quickstart.md): qualify a
  host, install the runtime, start its services, and run a first child.
- [`using-the-runtime.md`](using-the-runtime.md): opt-in `ctr` and Docker
  lifecycle, I/O, mount, and networking examples.
- [`kernel-and-bootstrap-artifacts.md`](kernel-and-bootstrap-artifacts.md):
  assemble, approve, and validate a child bootstrap artifact set.
- [`runtime-evidence-runbook.md`](runtime-evidence-runbook.md): capture,
  classify, sanitize, and validate evidence for a runtime gate.
- [`runtime-recovery-and-cleanup.md`](runtime-recovery-and-cleanup.md): preserve
  failure evidence, recover runtime authorities, and prove cleanup.
- [`developer-workflow.md`](developer-workflow.md): local build, test, contract,
  documentation, and live-test workflow for contributors.
- [`gce-lab-runbook.md`](gce-lab-runbook.md): build, boot, validate, recover,
  and clean up the verified Multikernel GCE laboratory.

Experiment-specific interpretations belong under `docs/experiments/`; future
runtime implementation gates belong under `docs/runtime/plans/`.
